## Descripción del Proyecto
Diseño, implementación y validación de un banco portátil de bajo costo para la calibración de lazos de corriente de 4-20 mA, orientado a aplicaciones agroindustriales. 

Este instrumento de diagnóstico interviene el lazo en campo para medir la corriente real de los sensores (humedad, nivel, etc.) y simular señales controladas hacia los Controladores Lógicos Programables (PLC), facilitando la detección rápida de fallas en entornos agrícolas.

## Hardware Utilizado
* Arduino Nano
* Amplificador Operacional LM358N
* Display TM1637
* Módulos reguladores DC-DC LM2596
